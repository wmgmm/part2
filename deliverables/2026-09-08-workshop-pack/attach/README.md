# AI in the Workplace, Part 2: the workshop pack

**The workshop website is the main thing:** https://wmgmm.github.io/part2/

Open it on the day and follow the six exercises. It has every prompt with a COPY button, every
file with a DOWNLOAD button, and the instructions step by step. **Sign in to Gemini and Copilot
with your Cardiff work account first.**

## In this folder (small enough to email)

| File | What it is |
|---|---|
| `Workshop_Hint_Sheets.pdf` | One page per exercise. A backup if the website is not reachable. |
| `Training_Module_Builder.md` | Skill 1, Exercise 04. Turns a document into a training session. |
| `Cardiff_Brand_SKILL.md` | Skill 2, Exercise 05. Makes a Notebook deck in Cardiff's voice and look. |
| `TheMattsBrandSkill.md` | Skill 3, Exercise 05 second run. Plain language first, then visual slides. |
| `Verify_And_Repair.md` | Skill 5, Exercise 06 and the bonus. Recomputes figures, does not just review. |
| `Fact_Check_Cardiff.md` | Skill 4. Checks claims against their sources. |
| `Example_Style_Block.md` | Exercise 02 backup: a reusable image prompt we made earlier. |
| `HESA_Estates_Workshop.csv` | Exercise 06 and the bonus: ten years of real estates data, 31 universities. |

A skill is a workflow written down. Attach it as a file in Copilot or Gemini, or paste it into
Gemini Notebook's description box, which takes text rather than files.
